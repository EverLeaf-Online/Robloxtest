# Documentation Archive

This directory contains historical project evidence that is intentionally **not** part of the active execution surface.

## Structure

- `status/` — dated validation and launch snapshots.
- `asset-pipelines/` — retired asset-production workflows.

## Rules

- `docs/ROADMAP.md` owns current phase/status/priorities.
- `docs/MASTER_PRODUCTION_PLAN.md` owns product/design/architecture specification.
- Active subsystem docs stay directly under `docs/`.
- Archived files may be cited for historical evidence, but they do not override the current roadmap or runtime code.
- Do not move an archived file back into active docs without explicitly re-adopting it.
